
## Install

Windows, in PowerShell:

```powershell
irm https://raw.githubusercontent.com/sne-sh/sne/main/install.ps1 | iex
```

macOS and Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/sne-sh/sne/main/install.sh | sh
```

Already have sne? Run `sne update`.

You can also download a file below: a setup wizard or portable zip for Windows, a `.pkg` for macOS, and `.deb`, `.rpm`, `.apk`, Arch or `.tar.gz` files for Linux. Each one is listed with its SHA-256 in `SHA256SUMS.txt`.
